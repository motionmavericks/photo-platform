# Project Brief: Photo Gallery Platform

## Overview
A modern photo gallery platform that enables administrators to manage and showcase photo collections. Built with Next.js 15 and Supabase, it allows admins to upload photos and organize them into albums with tags, while users can view, download, and share photos on social media.

## Core Requirements
1. Admin Authentication & Authorization
2. Photo & Album Management
   - Admin API for photo uploads
   - Album organization
   - Photo tagging system
3. User Experience
   - Public gallery viewing
   - Photo downloads
   - Social media sharing
4. Internationalization Support (i18n)
5. Dark/Light Theme Support

## Technical Goals
- Build a performant, scalable photo gallery system
- Implement secure admin authentication
- Create an intuitive admin API for photo management
- Develop a user-friendly gallery interface
- Support multiple languages (currently English and French)
- Ensure accessibility compliance
- Implement comprehensive testing
